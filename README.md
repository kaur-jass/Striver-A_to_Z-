## Running the Solutions

1. Clone the repository:

```bash
git clone https://github.com/kaur-jass/Striver-A_to_Z-.git
```

2. Navigate to the required problem directory.

3. Compile the C++ file:

```bash
g++ filename.cpp -o output
```

4. Execute the program:

**Windows (PowerShell):**
```powershell
.\output
```

**Linux:**
```bash
./output
```
